# AI游戏工坊 - 项目架构概览

## 项目简介

这是一个"一句话生成游戏"的Web应用，用户可以通过自然语言描述来生成可玩的HTML5小游戏。项目采用前后端一体的架构，使用Node.js + Express作为后端，纯HTML/CSS/JavaScript作为前端。

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Node.js + Express |
| 数据库 | SQLite (better-sqlite3) |
| 前端 | 原生HTML/CSS/JavaScript (无框架) |
| AI生成 | OpenAI兼容API (支持DeepSeek、OpenAI、Claude等) |
| 安全 | Helmet、express-rate-limit、bcrypt、xss-clean |
| 构建工具 | JavaScript Obfuscator (代码混淆) |

## 目录结构

```

├── repair-game.js         # 游戏静态文件修复工具

├── src/                   # 源代码目录
│   └── js/

│       └── security.js    # 前端安全脚本
│
├── public/                # 静态资源目录（对外服务）
│   ├── index.html         # 主页面（SPA入口）
│   ├── games.html         # 游戏列表页面
│   ├── admin.html         # 管理后台页面
│   ├── css/
│   │   └── style.css      # 全局样式
│   ├── js/
│   │   ├── app.js         # 混淆后的前端JS（由build.js生成）
│   │   └── security.js    # 混淆后的安全脚本
│   ├── images/            # 图片资源
│   └── g/                 # 生成的游戏静态HTML文件
```

## 核心文件说明

### 1. server.js（后端核心）
- 约7600行代码，包含所有API端点
- SQLite数据库初始化和表结构定义
- AI游戏生成逻辑
- 用户账号系统
- 积分系统
- 管理后台API

### 2. src/js/app.js（前端核心）
- 约8500行代码，包含所有前端交互逻辑
- 页面路由和导航
- 游戏展示和交互
- 用户状态管理
- 积分和账户功能

### 3. public/index.html（主页面）
- 单页应用(SPA)结构
- 包含首页、创作页、我的页面三个主标签
- 游戏详情页作为覆盖层显示

### 4. public/games.html（游戏列表页）
- 独立的游戏浏览页面
- 支持筛选、排序、分页
- 用于"更多"列表展示

## 数据流向

```
用户操作 → 前端(app.js) → API请求 → 后端(server.js) → SQLite数据库
                                           ↓
                                    AI API (生成游戏)
                                           ↓
                                    静态HTML文件 → /g/{xx}/{id}.html
```

## 部署方式

支持多种部署方式：
1. **本地开发**: `node server.js` (默认端口3000)
2. **Render**: 使用 `render.yaml` 配置
3. **Vercel**: 使用 `api/` 目录的Serverless函数
4. **Zeabur**: 使用 `zeabur.json` 配置

## 环境变量

参考 `.env.example` 文件，主要配置项：
- `ADMIN_PASSWORD`: 管理后台密码
- `LLM_API_KEY`: AI API密钥
- `LLM_BASE_URL`: AI API地址
- `PORT`: 服务端口号

## 快速启动

```bash
# 安装依赖
npm install

# 开发模式（使用源码）
node server.js

# 生产构建（混淆代码）
node build.js

# Windows快捷启动
start.bat
```
