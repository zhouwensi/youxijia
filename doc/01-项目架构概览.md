# AI游戏工坊 - 项目架构概览

## 项目简介

这是一个"一句话生成游戏"的Web应用，用户可以通过自然语言描述来生成可玩的HTML5小游戏。项目采用前后端一体的架构，使用Node.js + Express作为后端，纯HTML/CSS/JavaScript作为前端，支持多种AI模型，具备完整的用户系统、积分系统、社交功能和管理后台。

## 核心功能

- 🎮 **AI游戏生成**: 一句话描述，AI自动生成可玩的HTML5游戏
- ✏️ **游戏编辑器**: 对已生成的游戏进行AI辅助修改优化
- 👤 **用户系统**: 设备指纹识别 + 账号密码登录
- 💰 **积分系统**: 生成消耗积分，多种途径获取
- ❤️ **互动功能**: 点赞、收藏、评论、分享
- 👥 **社交功能**: 关注创作者、查看他人作品
- 🏆 **排行榜**: 热门游戏、优秀创作者榜单
- 🎁 **邀请系统**: 邀请好友获取积分奖励
- 🔧 **管理后台**: 游戏管理、用户管理、系统配置

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Node.js + Express |
| 数据库 | SQLite (better-sqlite3) |
| 前端 | 原生HTML/CSS/JavaScript (无框架) |
| AI生成 | OpenAI兼容API (支持DeepSeek、OpenAI、Claude、Gemini等) |
| 安全 | Helmet、express-rate-limit、bcrypt、xss-clean |
| 构建工具 | JavaScript Obfuscator (代码混淆) |

## 核心文件说明

### 1. server.js（后端核心）
- 约9500行代码，包含126个API端点
- SQLite数据库初始化和表结构定义
- AI游戏生成逻辑（支持多模型）
- 游戏编辑器功能
- 用户账号系统（设备指纹 + 密码登录）
- 积分系统（获取与消耗）
- 社交功能（关注、评论）
- 邀请奖励系统
- 排行榜功能
- 管理后台API
- 安全机制（封禁、白名单）

### 2. src/js/app.js（前端核心）
- 约8500行代码，包含所有前端交互逻辑
- 页面路由和导航（SPA）
- 游戏展示和交互
- 游戏生成界面（高级设置、模型选择）
- 游戏编辑器（AI辅助修改）
- 用户状态管理
- 积分和账户功能
- 社交功能（关注、评论）
- 搜索功能
- 下拉刷新、无限滚动

### 3. public/index.html（主页面）
- 约2200行，单页应用(SPA)结构
- 包含首页、创作页、我的页面三个主标签
- 游戏详情页作为覆盖层显示
- 游戏编辑器模态框
- 搜索面板
- 各种功能模态框

### 4. public/games.html（游戏列表页）
- 独立的游戏浏览页面
- 支持筛选、排序、分页
- 用于"更多"列表展示

### 5. public/admin.html（管理后台）
- 管理员专用页面
- 游戏管理、用户管理
- 系统配置、数据统计
- 安全设置（封禁、白名单）

## 数据流向

```
用户操作 → 前端(app.js) → API请求 → 后端(server.js) → SQLite数据库
                                           ↓
                                    AI API (生成/编辑游戏)
                                           ↓
                                    静态HTML文件 → /g/{xx}/{id}.html
```

## AI模型支持

项目支持多种AI模型用于游戏生成：
- **DeepSeek**: deepseek-v3, deepseek-chat
- **OpenAI**: gpt-4o, gpt-4-turbo, gpt-3.5-turbo
- **Claude**: claude-3-sonnet, claude-3-haiku
- **Gemini**: gemini-pro
- 其他OpenAI兼容API

用户可以：
- 使用系统提供的免费/积分模型
- 配置自己的API Key使用更多模型
- 生成过程中选择"加速"切换到更快的模型

## 部署方式

支持多种部署方式：
1. **本地开发**: `node server.js` (默认端口3000)
2. **Render**: 使用 `render.yaml` 配置
3. **Vercel**: 使用 `api/` 目录的Serverless函数
4. **Zeabur**: 使用 `zeabur.json` 配置
5. **Cloudflare Workers**: 使用 `wrangler.toml` 配置

## 环境变量

参考 `.env.example` 文件，主要配置项：

| 变量 | 说明 |
|------|------|
| `ADMIN_PASSWORD` | 管理后台密码 |
| `LLM_API_KEY` | AI API密钥 |
| `LLM_BASE_URL` | AI API地址 |
| `LLM_MODEL` | 默认使用的模型 |
| `PORT` | 服务端口号 |
| `FREE_GENERATE` | 是否开放免费生成 |
| `CREDITS_PER_GENERATION` | 每次生成消耗积分 |

## 快速启动

```bash
# 安装依赖
npm install

# 开发模式（使用源码）
node server.js

# 生产构建（混淆代码）
node build.js

# Windows快捷启动
start.bat

# Windows停止服务
stop.bat
```

## 安全机制

1. **设备指纹**: 基于浏览器特征生成唯一标识
2. **账号系统**: 支持密码保护和账号恢复
3. **封禁系统**: 支持封禁账号/IP
4. **开发者工具检测**: 可配置白名单
5. **请求限流**: 防止API滥用
6. **代码混淆**: 生产环境前端代码混淆
