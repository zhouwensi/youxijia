## 核心表详解

### 1. games（游戏表）

这是最核心的表，存储所有生成的游戏。

```sql
CREATE TABLE games (
    id TEXT PRIMARY KEY,                    -- 游戏唯一ID（UUID格式）
    title TEXT NOT NULL,                    -- 游戏标题
    prompt TEXT NOT NULL,                   -- 用户输入的原始提示词
    code TEXT NOT NULL,                     -- 生成的完整HTML游戏代码
    author_name TEXT DEFAULT '匿名',        -- 作者昵称
    author_token TEXT NOT NULL,             -- 作者Token（用于识别创建者）
    
    -- 统计信息
    play_count INTEGER DEFAULT 0,           -- 游玩次数
    like_count INTEGER DEFAULT 0,           -- 点赞数
    favorite_count INTEGER DEFAULT 0,       -- 收藏数（ALTER ADD）
    share_count INTEGER DEFAULT 0,          -- 分享数（ALTER ADD）
    
    -- 管理信息
    is_featured INTEGER DEFAULT 0,          -- 是否精选/置顶
    is_hidden INTEGER DEFAULT 0,            -- 是否隐藏（ALTER ADD）
    is_public INTEGER DEFAULT 1,            -- 是否公开（ALTER ADD）
    
    -- 游戏属性
    category TEXT DEFAULT '其他',           -- 游戏分类（ALTER ADD）
    status TEXT DEFAULT 'published',        -- 状态: draft/published（ALTER ADD）
    visibility TEXT DEFAULT 'public',       -- 可见性: public/followers/private（ALTER ADD）
    orientation TEXT DEFAULT 'portrait',    -- 屏幕方向: portrait/landscape（ALTER ADD）
    
    -- AI相关
    llm_model TEXT DEFAULT 'deepseek-v3',   -- 使用的AI模型（ALTER ADD）
    
    -- 时间戳
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

> **注意**: 标有 `(ALTER ADD)` 的字段是通过 `ALTER TABLE` 动态添加的，数据库初始化时会自动检测并添加。

**索引**：
```sql
CREATE INDEX idx_games_created_at ON games(created_at DESC);
CREATE INDEX idx_games_featured ON games(is_featured DESC, like_count DESC);
```

### 2. user_accounts（用户账号表）

```sql
CREATE TABLE user_accounts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    account_id TEXT UNIQUE NOT NULL,        -- 账号ID（如 "玩家12345"）
    nickname TEXT DEFAULT '游戏玩家',       -- 昵称
    password_hash TEXT,                     -- 密码哈希
    email TEXT,                             -- 邮箱（可选）
    user_token TEXT UNIQUE NOT NULL,        -- 用户Token（设备指纹）
    has_password INTEGER DEFAULT 0,         -- 是否已设置密码
    device_fingerprint TEXT,                -- 设备指纹（ALTER ADD）
    last_ip TEXT,                           -- 最后登录IP（ALTER ADD）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

**索引**：
```sql
CREATE INDEX idx_user_accounts_account_id ON user_accounts(account_id);
CREATE INDEX idx_user_accounts_user_token ON user_accounts(user_token);
CREATE INDEX idx_user_accounts_device_fingerprint ON user_accounts(device_fingerprint);
```

### 3. user_likes（点赞表）

```sql
CREATE TABLE user_likes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL,                  -- 用户ID或设备指纹
    game_id TEXT NOT NULL,                  -- 游戏ID
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, game_id)                -- 每人每游戏只能点赞一次
)
```

---

### 4. user_favorites（收藏表）

```sql
CREATE TABLE user_favorites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL,                  -- 用户ID
    game_id TEXT NOT NULL,                  -- 游戏ID
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, game_id)
)
```

---

### 5. user_game_history（游戏历史记录表）

```sql
CREATE TABLE user_game_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL,                  -- 用户ID（设备指纹）
    game_id TEXT NOT NULL,                  -- 游戏ID
    play_count INTEGER DEFAULT 1,           -- 该游戏的游玩次数
    last_played_at TEXT,                    -- 最后游玩时间
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
)
```

---

### 6. comments（评论表）

```sql
CREATE TABLE comments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    game_id TEXT NOT NULL,                  -- 游戏ID
    user_id TEXT,                           -- 评论者ID
    user_name TEXT,                         -- 评论者昵称
    content TEXT NOT NULL,                  -- 评论内容
    parent_id INTEGER,                      -- 父评论ID（用于回复）
    like_count INTEGER DEFAULT 0,           -- 点赞数
    status TEXT DEFAULT 'visible',          -- 状态
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
)
```

---

### 7. game_collections（游戏合集表）

```sql
CREATE TABLE game_collections (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,                    -- 合集标题
    description TEXT,                       -- 合集描述
    cover_image TEXT,                       -- 封面图片
    games TEXT,                             -- 游戏ID列表（JSON数组）
    sort_order INTEGER DEFAULT 0,           -- 排序权重
    status TEXT DEFAULT 'active',           -- 状态
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
)
```

---

### 8. feedback（用户反馈表）

```sql
CREATE TABLE feedback (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT,                           -- 用户ID
    type TEXT,                              -- 反馈类型
    content TEXT,                           -- 反馈内容
    contact TEXT,                           -- 联系方式
    status TEXT DEFAULT 'pending',          -- 处理状态
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
)
```

---

### 9. site_stats（站点统计表）

```sql
CREATE TABLE site_stats (
    key TEXT PRIMARY KEY,                   -- 统计项名称
    value TEXT,                             -- 统计值
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
)
```

常用统计项：
- `total_visits`: 总访问量
- `unique_visitors`: 独立访客数
- `guest_counter`: 游客计数器（用于生成游客昵称）

---

### 10. settings（系统设置表）

```sql
CREATE TABLE settings (
    key TEXT PRIMARY KEY,                   -- 设置项名称
    value TEXT,                             -- 设置值
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
)
```

常用设置项：
- `site_name`: 站点名称
- `announcement`: 公告内容
- `generation_cost`: 生成游戏消耗积分
- `daily_free_generations`: 每日免费生成次数

## 重要查询模式

### 热门游戏排序（精选优先）
```sql
SELECT * FROM games 
WHERE is_hidden = 0 AND is_public = 1
ORDER BY is_featured DESC, like_count DESC, play_count DESC
LIMIT 20
```

### 最新游戏
```sql
SELECT * FROM games 
WHERE is_hidden = 0 AND is_public = 1
ORDER BY created_at DESC
LIMIT 20
```

### 用户的游戏列表（根据author_token）
```sql
SELECT * FROM games 
WHERE author_token = ?
ORDER BY created_at DESC
```

### 用户的收藏列表
```sql
SELECT g.* FROM games g
INNER JOIN user_favorites f ON g.id = f.game_id
WHERE f.user_id = ?
ORDER BY f.created_at DESC
```

### 用户的点赞列表
```sql
SELECT g.* FROM games g
INNER JOIN user_likes l ON g.id = l.game_id
WHERE l.user_id = ?
ORDER BY l.created_at DESC
```
