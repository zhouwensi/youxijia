数据库使用SQLite，文件位置：`games.db`

## 核心表详解

### 1. games（游戏表）

这是最核心的表，存储所有生成的游戏。

```sql
CREATE TABLE games (
    id TEXT PRIMARY KEY,                    -- 游戏唯一ID（UUID格式）
    title TEXT NOT NULL,                    -- 游戏标题
    prompt TEXT NOT NULL,                   -- 用户输入的原始提示词
    code TEXT NOT NULL,                     -- 生成的完整HTML游戏代码
    author_name TEXT DEFAULT '匿名',        -- 作者昵称
    author_token TEXT NOT NULL,             -- 作者Token（用于识别创建者）
    
    -- 统计信息
    play_count INTEGER DEFAULT 0,           -- 游玩次数
    like_count INTEGER DEFAULT 0,           -- 点赞数
    favorite_count INTEGER DEFAULT 0,       -- 收藏数（ALTER ADD）
    share_count INTEGER DEFAULT 0,          -- 分享数（ALTER ADD）
    
    -- 管理信息
    is_featured INTEGER DEFAULT 0,          -- 是否精选/置顶
    is_hidden INTEGER DEFAULT 0,            -- 是否隐藏（ALTER ADD）
    is_public INTEGER DEFAULT 1,            -- 是否公开（ALTER ADD）
    
    -- 游戏属性
    category TEXT DEFAULT '其他',           -- 游戏分类（ALTER ADD）
    status TEXT DEFAULT 'published',        -- 状态: draft/published（ALTER ADD）
    visibility TEXT DEFAULT 'public',       -- 可见性: public/followers/private（ALTER ADD）
    orientation TEXT DEFAULT 'portrait',    -- 屏幕方向: portrait/landscape（ALTER ADD）
    
    -- AI相关
    llm_model TEXT DEFAULT 'deepseek-v3',   -- 使用的AI模型（ALTER ADD）
    
    -- 时间戳
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

> **注意**: 标有 `(ALTER ADD)` 的字段是通过 `ALTER TABLE` 动态添加的，数据库初始化时会自动检测并添加。

**索引**：
```sql
CREATE INDEX idx_games_created_at ON games(created_at DESC);
CREATE INDEX idx_games_featured ON games(is_featured DESC, like_count DESC);
```

### 2. user_accounts（用户账号表）

```sql
CREATE TABLE user_accounts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    account_id TEXT UNIQUE NOT NULL,        -- 账号ID（如 "玩家12345"）
    nickname TEXT DEFAULT '游戏玩家',       -- 昵称
    password_hash TEXT,                     -- 密码哈希
    email TEXT,                             -- 邮箱（可选）
    user_token TEXT UNIQUE NOT NULL,        -- 用户Token（设备指纹）
    has_password INTEGER DEFAULT 0,         -- 是否已设置密码
    device_fingerprint TEXT,                -- 设备指纹（ALTER ADD）
    last_ip TEXT,                           -- 最后登录IP（ALTER ADD）
    is_admin INTEGER DEFAULT 0,             -- 是否为管理员（ALTER ADD）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

**管理员说明**：
- `is_admin = 1` 表示该用户为管理员
- 管理员可以编辑任何公开可见的游戏（`is_public = 1` 且 `visibility = 'public'`）
- 在后台用户管理页面可以设置/取消用户的管理员权限

**索引**：
```sql
CREATE INDEX idx_user_accounts_account_id ON user_accounts(account_id);
CREATE INDEX idx_user_accounts_user_token ON user_accounts(user_token);
CREATE INDEX idx_user_accounts_device_fingerprint ON user_accounts(device_fingerprint);
```

### 6. comments（评论表）

CREATE TABLE comments (

### 9. site_stats（站点统计表）

```sql
CREATE TABLE site_stats (
    key TEXT PRIMARY KEY,                   -- 统计项名称
    value TEXT,                             -- 统计值
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
)
```

常用统计项：
- `total_visits`: 总访问量
- `unique_visitors`: 独立访客数
- `guest_counter`: 游客计数器（用于生成游客昵称）

### 10. settings（系统设置表）

```sql
CREATE TABLE settings (
    key TEXT PRIMARY KEY,                   -- 设置项名称
    value TEXT,                             -- 设置值
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
)
```

常用设置项：
- `site_name`: 站点名称
- `announcement`: 公告内容
- `generation_cost`: 生成游戏消耗积分
- `daily_free_generations`: 每日免费生成次数

---

### 11. daily_action_credits（每日行为积分记录表）

用于记录用户每日各类行为已获得的积分次数，实现每日上限控制。

```sql
CREATE TABLE daily_action_credits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_token TEXT NOT NULL,              -- 用户Token
    action_type TEXT NOT NULL,             -- 行为类型: like/favorite/follow/comment
    action_date TEXT NOT NULL,             -- 日期 (YYYY-MM-DD)
    count INTEGER DEFAULT 0,               -- 当日已获得次数
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_token, action_type, action_date)
)
```

---

### 12. comment_credit_logs（评论积分记录表）

用于确保同一游戏仅首次评论可获得积分。

```sql
CREATE TABLE comment_credit_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_token TEXT NOT NULL,              -- 用户Token
    game_id TEXT NOT NULL,                 -- 游戏ID
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_token, game_id)            -- 每人每游戏只能获得一次评论积分
)
```

---

### 13. leaderboard_excludes（榜单排除名单表）

用于管理不参与排行榜排名的用户（如官方账号、测试账号等）。

```sql
CREATE TABLE leaderboard_excludes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_token TEXT UNIQUE NOT NULL,       -- 被排除的用户Token
    exclude_types TEXT DEFAULT 'all',      -- 排除的榜单类型
                                           -- 'all' 表示所有榜单
                                           -- 或逗号分隔: 'fans,works,credits,popularity'
    reason TEXT,                           -- 排除原因
    operator TEXT DEFAULT 'admin',         -- 操作者
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

**榜单类型说明**：
| 类型 | 说明 |
|------|------|
| `all` | 排除所有榜单 |
| `fans` | 排除粉丝榜 |
| `works` | 排除作品榜 |
| `credits` | 排除积分榜 |
| `popularity` | 排除人气榜 |

## 积分系统配置

以下配置项存储在 `system_config` 表中：

### 基础积分配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `credits_initial` | 3 | 新用户初始积分 |
| `credits_follow_wechat` | 3 | 关注公众号奖励 |
| `credits_watch_ad` | 1 | 看广告奖励 |
| `credits_daily_ad_limit` | 3 | 每日广告上限 |

### 分享与邀请积分配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `credits_share_game` | 1 | 分享游戏奖励 |
| `credits_share_game_daily_limit` | 5 | 每日分享游戏获取积分上限次数 |
| `credits_invite_friend` | 3 | 邀请好友奖励 |
| `credits_invite_friend_daily_limit` | 5 | 每日邀请好友获取积分上限次数 |
| `credits_article` | 1 | 阅读文章奖励 |
| `credits_article_daily_limit` | 3 | 每日阅读文章获取积分上限次数 |

### 行为积分配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `credits_action_like` | 0.1 | 点赞作品奖励积分 |
| `credits_action_like_daily_limit` | 10 | 每日点赞获取积分上限次数 |
| `credits_action_favorite` | 0.2 | 收藏作品奖励积分 |
| `credits_action_favorite_daily_limit` | 5 | 每日收藏获取积分上限次数 |
| `credits_action_follow` | 0.2 | 关注别人奖励积分 |
| `credits_action_follow_daily_limit` | 5 | 每日关注获取积分上限次数 |
| `credits_action_comment` | 0.5 | 评论作品奖励积分 |
| `credits_action_comment_daily_limit` | 2 | 每日评论获取积分上限次数 |
| `credits_comment_min_length` | 10 | 评论获得积分的最低字数 |

### 积分规则说明

**一次性奖励：**
- 新用户注册自动获得初始积分
- 首次关注公众号可获得积分奖励

**每日可重复获取（每日刷新）：**
- 点赞、收藏、关注、评论、分享、邀请、阅读文章等操作每天都可获得积分
- 达到每日上限后第二天重置

**保底机制：**
- 当用户积分为0时，每日登录可获得1积分

**限制规则：**
- 取消操作（取消点赞/收藏/关注）不会扣除已获得的积分
- 对自己的作品点赞、收藏、评论不会获得积分
- 评论需满足最低字数要求，且同一游戏仅首次评论可获得积分
- 评论内容与当日其他评论相似度>80%不给积分（防止刷分）

## 重要查询模式

### 热门游戏排序（精选优先）
```sql
SELECT * FROM games 
WHERE is_hidden = 0 AND is_public = 1
ORDER BY is_featured DESC, like_count DESC, play_count DESC
LIMIT 20
```

### 最新游戏
```sql
SELECT * FROM games 
WHERE is_hidden = 0 AND is_public = 1
ORDER BY created_at DESC
LIMIT 20
```

### 用户的游戏列表（根据author_token）
```sql
SELECT * FROM games 
WHERE author_token = ?
ORDER BY created_at DESC
```

### 用户的收藏列表
```sql
SELECT g.* FROM games g
INNER JOIN user_favorites f ON g.id = f.game_id
WHERE f.user_id = ?
ORDER BY f.created_at DESC
```

### 用户的点赞列表
```sql
SELECT g.* FROM games g
INNER JOIN user_likes l ON g.id = l.game_id
WHERE l.user_id = ?
ORDER BY l.created_at DESC
```
