# AI游戏工坊 - 前端架构

前端使用纯HTML/CSS/JavaScript构建，无任何框架依赖。

## 页面结构

### 1. 主页面 (`public/index.html`)

这是一个单页应用(SPA)结构，包含三个主标签页：

```
index.html
├── 首页 (home-page)
│   ├── 搜索栏
│   ├── 分类导航
│   ├── 排行榜滑动展示 (leaderboards-swiper)
│   └── 游戏列表（分组展示）
│
├── 创作 (create-page)
│   ├── 提示词输入框
│   ├── 生成按钮
│   └── 生成中状态显示
│
├── 我的 (profile-page)
│   ├── 用户信息卡片
│   ├── 我的作品列表
│   ├── 我的点赞列表
│   ├── 我的收藏列表
│   └── 游戏历史记录
│
└── 游戏详情 (game-detail-overlay)
    ├── 游戏展示区 (使用 <iframe> 加载游戏代码)
    ├── 游戏信息
    ├── 点赞/收藏按钮
    └── 分享/编辑按钮
```

> **技术说明**：游戏通过 `<iframe id="game-frame">` 展示，使用 `iframe.srcdoc` 直接注入HTML代码，或通过 Blob URL 加载。

### 2. 游戏列表页 (`public/games.html`)

独立的游戏浏览页面，支持：
- 按分类筛选
- 多种排序方式
- 分页加载
- 搜索功能

**URL参数**：
| 参数 | 说明 |
|------|------|
| source | 数据来源：my-games/my-likes/my-favorites |
| category | 游戏分类 |
| sort | 排序方式：latest/popular/oldest |
| search | 搜索关键词 |
| page | 页码 |

### 3. 管理后台 (`public/admin.html`)

管理员专用页面，功能包括：
- 游戏管理（审核、删除、编辑）
- 用户管理
- 系统设置
- 统计数据

## 路由机制

前端实现了一个简易的路由系统：

```javascript
// URL参数处理
function handleRouting() {
  const params = new URLSearchParams(window.location.search);
  
  // 处理标签页切换
  const tab = params.get('tab');
  if (tab === 'profile') {
    directSwitchToTab('profile');
  } else if (tab === 'create') {
    directSwitchToTab('create');
  }
  
  // 处理游戏详情
  const gameId = params.get('game');
  if (gameId) {
    showGameDetail(gameId);
  }
}
```

### 支持的URL格式

```
/                     → 首页
/?tab=profile         → 我的页面
/?tab=create          → 创作页面
/?game=xxx            → 打开游戏详情
/games.html?source=my-games     → 我的游戏列表
/games.html?category=益智       → 分类游戏列表
/games.html?sort=popular        → 按热度排序
```

## 组件模式

虽然没有使用框架，但代码中有一些组件化的模式：

### 游戏卡片组件

```javascript
function renderGameCard(game, options = {}) {
  const { showAuthor = true, cardSize = 'normal' } = options;
  
  return `
    <div class="game-card ${cardSize}" data-id="${game.id}">
      <div class="game-thumbnail">
        <img src="${game.thumbnail || '/images/default-game.png'}" alt="${game.title}">
        <div class="play-count">${formatNumber(game.play_count)} 次游玩</div>
      </div>
      <div class="game-info">
        <h3 class="game-title">${escapeHtml(game.title)}</h3>
        ${showAuthor ? `<p class="game-author">${escapeHtml(game.author_name)}</p>` : ''}
      </div>
    </div>
  `;
}
```

### Toast 提示组件

```javascript
function showToast(message, type = 'info', duration = 3000) {
  const toast = document.createElement('div');
  toast.className = `toast toast-${type}`;
  toast.textContent = message;
  document.body.appendChild(toast);
  
  setTimeout(() => toast.remove(), duration);
}
```

```javascript
// 游戏卡片点击
document.querySelector('.games-grid').addEventListener('click', (e) => {
  const card = e.target.closest('.game-card');
  if (card) {
    const gameId = card.dataset.id;
    showGameDetail(gameId);
  }

// 底部导航切换
document.querySelector('.bottom-nav').addEventListener('click', (e) => {
  const navItem = e.target.closest('.nav-item');
  if (navItem) {
    const tab = navItem.dataset.tab;
    switchBottomNav(tab);
  }
});
```

## 性能优化

### 1. 图片懒加载

```javascript
// 使用 IntersectionObserver
const imageObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      imageObserver.unobserve(img);
    }
  });
});
```

### 2. 虚拟滚动（大列表）

对于游戏列表，使用分页加载而非一次性加载所有数据。

### 3. 防抖节流

```javascript
// 搜索防抖
const debouncedSearch = debounce((keyword) => {
  searchGames(keyword);
}, 300);

// 滚动节流
window.addEventListener('scroll', throttle(() => {
  checkLoadMore();
}, 100));
```
