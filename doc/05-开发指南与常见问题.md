# AI游戏工坊 - 开发指南与常见问题

## 开发环境搭建

### 1. 环境要求
- Node.js >= 16.x
- npm >= 8.x

### 2. 安装依赖
```bash
cd youxijia
npm install
```

### 3. 配置环境变量
```bash
# 复制示例配置文件
copy .env.example .env

# 编辑 .env 文件，填写必要配置
# LLM_API_KEY=你的API密钥
# ADMIN_PASSWORD=管理后台密码
```

### 4. 启动服务
```bash
# 开发模式
node server.js

# 或使用 Windows 批处理
start.bat
```

服务默认运行在 `http://localhost:3000`

---

## 开发工作流

### 前端开发

1. **源文件位置**: `src/js/app.js`
2. **开发时**: 服务器直接使用 `src/js/app.js`（未混淆版本）
3. **生产构建**: 运行 `node build.js` 生成混淆后的 `public/js/app.js`

### 后端开发

直接修改 `server.js`，重启服务即可生效。

### 样式修改

直接修改 `public/css/style.css`，刷新页面即可。

## 代码规范

### JavaScript
- 使用驼峰命名法
- 函数名使用动词开头（如 `loadGames`, `showDetail`）
- 异步函数使用 `async/await`
- 使用 `const` 和 `let`，避免 `var`

### API设计
- RESTful风格
- 统一响应格式 `{ success, data, error }`
- 使用HTTP状态码表示结果

## 关键功能实现

### Token认证机制

项目使用Token机制识别用户，user-token 和 author-token 通常是相同的值：

```javascript
// 获取或生成设备指纹作为Token
let token = localStorage.getItem('aigame-author-token');
if (!token) {
  token = localStorage.getItem('aigame-user-token');
}
if (!token) {
  token = generateFingerprint(); // 生成设备指纹
}

// 统一保存到两个key
localStorage.setItem('aigame-user-token', token);
localStorage.setItem('aigame-author-token', token);
```

**注意**: 在 `games.html` 等独立页面中，需要确保Token读取逻辑一致，兼容旧版键名：

```javascript
function getUserToken() {
  return localStorage.getItem('aigame-user-token') 
      || localStorage.getItem('aigame-author-token')
      || localStorage.getItem('user_token') 
      || '';
}

function getAuthorToken() {
  return localStorage.getItem('aigame-author-token') 
      || localStorage.getItem('aigame-user-token')
      || localStorage.getItem('user_token') 
      || '';
}
```

### 游戏生成流程

```
1. 用户输入提示词
2. 前端调用 POST /api/generate
3. 后端验证用户积分/权限
4. 调用 AI API 生成游戏代码
5. 从返回的代码中提取元信息（标题、描述等）
6. 保存到数据库
7. 生成静态HTML文件到 /g/{xx}/{id}.html
8. 返回游戏信息给前端
```

### 路由与导航

从子页面返回主页特定标签：

```javascript
// games.html 中设置返回链接
if (source === 'my-games' || source === 'my-likes' || source === 'my-favorites') {
  backLink.href = '/?tab=profile';
}

// index.html 中处理路由
function handleRouting() {
  const params = new URLSearchParams(window.location.search);
  const tab = params.get('tab');
  if (tab === 'profile') {
    directSwitchToTab('profile');  // 使用无动画切换避免闪烁
  }
}
```

## 常见问题与解决方案

### Q1: 数据不显示（"共 0 个游戏"）

**原因**: Token不一致导致API无法识别用户

**解决**: 确保不同页面使用相同的LocalStorage键名读取Token

```javascript
// 错误示例
localStorage.getItem('userToken')  // games.html使用

// 正确示例  
localStorage.getItem('aigame-user-token')  // 与app.js一致
```

### Q2: 返回按钮导航错误

**原因**: 返回链接硬编码为 `/`

**解决**: 根据来源动态设置返回地址

```javascript
const backLink = document.querySelector('.back-link');
if (source.startsWith('my-')) {
  backLink.href = '/?tab=profile';
} else {
  backLink.href = '/';
}
```

### Q3: 页面切换时闪烁

**原因**: 使用带动画的切换函数，且执行顺序不当

**解决**: 
1. 创建无动画的直接切换函数
2. 在 `DOMContentLoaded` 中先处理路由，再初始化其他模块

```javascript
document.addEventListener('DOMContentLoaded', () => {
  handleRouting();     // 先处理路由
  initMainTabs();      // 再初始化UI
  loadInitialData();   // 最后加载数据
});
```

### Q4: 游戏详情页无法点赞

**原因**: `x-user-token` 请求头未正确设置

**解决**: 确保API请求包含正确的Header

```javascript
fetch(`/api/games/${gameId}/like`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-user-token': getUserToken()
  }
});
```

### Q5: 开发环境与生产环境表现不一致

**原因**: 生产环境使用混淆后的代码

**解决**: 
1. 确保修改的是 `src/js/app.js`
2. 每次部署前运行 `node build.js`
3. 检查 `server.js` 中的静态文件配置

### Q6: 数据库被锁定

**原因**: SQLite并发写入冲突

**解决**:
1. 确保只有一个服务器实例在运行
2. 使用 `better-sqlite3` 的同步API避免冲突

## 调试技巧

### 1. 查看数据库内容

```bash
# 安装sqlite3命令行工具，或使用DB Browser for SQLite
sqlite3 games.db

# 查看表结构
.schema games

# 查看数据
SELECT id, title, status FROM games LIMIT 10;
```

### 2. API调试

```bash
# 使用curl测试API
curl http://localhost:3000/api/games?limit=5

# 带Token的请求
curl -H "x-user-token: your_token" http://localhost:3000/api/my-likes
```

### 3. 前端调试

在浏览器控制台中：
```javascript
// 查看当前Token
console.log(localStorage.getItem('aigame-user-token'));
console.log(localStorage.getItem('aigame-author-token'));

// 手动触发函数
loadMyGames();

```

### 4. 日志查看

服务器日志会输出到控制台，包括：
- API请求日志
- 错误信息
- AI生成进度

## 扩展开发建议

### 添加新API

1. 在 `server.js` 中添加路由
2. 在 `src/js/app.js` 中添加调用函数
3. 更新 `doc/03-API接口文档.md`

### 添加新页面

1. 在 `public/` 下创建HTML文件
2. 确保Token读取逻辑与主应用一致
3. 复用 `style.css` 样式

### 修改数据库结构

1. 在 `server.js` 的 `initDatabase()` 中修改表结构
2. 添加数据迁移逻辑（如果需要）
3. 更新 `doc/02-数据库架构.md`
