# 小程序积分引流方案设计

> 版本: v2.3  
> 更新时间: 2025-02-05  
> 状态: ✅ 已实现

## 一、背景与目标

### 问题
- 微信不允许个人开发者发布AI功能小程序
- 需要小程序的流量入口和广告变现能力

### 解决方案
- 小程序移除AI生成功能，仅保留游戏浏览、社交互动功能
- 网站端负责AI生成功能
- 通过积分体系引导用户在小程序端获取积分

### 目标
- 小程序顺利通过审核
- 引导用户频繁使用小程序（为后续广告变现做准备）
- 建立网站与小程序的用户粘性闭环

## 二、积分体系设计

### 2.1 网站端（仅基础积分，其余只记录行为）

| 类型 | 积分 | 说明 |
|------|------|------|
| 🆕 新用户注册 | +1 | 仅一次 |
| 📅 每日登录 | +1 | 每天首次访问 |
| **其他操作** | **0** | 只记录次数，不给积分 |

**网站端只记录行为，不发放互动积分：**

| 操作 | 网站行为 | 达成条件 → 小程序领取 |
|------|---------|---------------------|
| ❤️ 点赞 | 记录次数 | 每10次可领1积分 |
| ⭐ 收藏 | 记录次数 | 每5次可领1积分 |
| 👥 关注 | 记录次数 | 每5次可领1积分 |
| 💬 评论 | 记录次数 | 每2次可领1积分 |
| 🔗 分享 | 记录次数 | 每2次可领1积分 |
| 🎮 创作游戏 | 记录次数 | 每1次可领2积分（每日） |
| ✏️ 编辑游戏 | 记录次数 | 每2次可领1积分（每日） |

### 2.2 小程序端（积分发放中心）

| 功能 | 积分 | 说明 |
|------|------|------|
| 📅 每日签到 | +1 | 小程序独占 |
| 📆 连续签到加成 | +1~5 | 见下表 |
| 🏆 互动积分领取 | +N | 网站做任务，小程序领取 |
| 🎖️ 成就奖励领取 | +N | 网站达成，小程序领取 |
| 👥 邀请好友 | +5 | 好友首次创作后双方得 |
| 🎬 激励视频广告 | +3 | **待500UV后开通** |

#### 连续签到加成规则

| 连续天数 | 额外奖励 |
|---------|---------|
| 3天 | +1积分 |
| 7天 | +2积分 |
| 14天 | +3积分 |
| 30天 | +5积分 |

## 三、成就系统设计

### 3.1 每日重置成就（小程序领取）

| 成就名称 | 达成条件 | 奖励 |
|---------|---------|------|
| 日活跃 | 登录+任意1次互动 | 1积分 |
| 互动达标 | 点赞+收藏+关注各完成每日上限 | 3积分 |
| 社区贡献 | 发表1条有效评论 | 1积分 |

**每日成就：最多 5 积分/天**

### 3.2 每周重置成就（小程序领取）

| 成就名称 | 达成条件 | 奖励 |
|---------|---------|------|
| 周活跃之星 | 连续登录7天 | 5积分 |
| 周点赞达人 | 本周点赞50次 | 5积分 |
| 周收藏家 | 本周收藏20次 | 5积分 |
| 周社交王 | 本周关注15人 | 5积分 |
| 周评论家 | 本周发表7条评论 | 5积分 |

**每周成就：最多 25 积分/周（每周一重置）**

### 3.3 每月重置成就（小程序领取）

| 成就名称 | 达成条件 | 奖励 |
|---------|---------|------|
| 月度活跃 | 本月登录20天 | 15积分 |
| 月度互动王 | 本月互动满300次 | 20积分 |
| 月度创作者 | 本月创作2个游戏 | 20积分 |
| 月度人气 | 本月作品获100赞 | 25积分 |

**每月成就：最多 80 积分/月（每月1日重置）**

### 3.4 永久成就（一次性）

| 成就名称 | 达成条件 | 奖励 |
|---------|---------|------|
| 初来乍到 | 首次登录 | 3积分 |
| 首次创作 | 发布首个游戏 | 5积分 |
| 百赞作者 | 单作品获100赞 | 20积分 |
| 千赞大神 | 单作品获1000赞 | 100积分 |
| 创作大师 | 累计创作50个游戏 | 50积分 |
| 社区元老 | 注册满1年 | 50积分 |

## 四、积分对比

| 来源 | 网站端 | 小程序端 |
|------|--------|----------|
| 注册/每日登录 | 1+1积分 | - |
| 互动积分领取 | - | ~5积分/天 |
| 每日签到 | - | 1积分 |
| 每日成就 | - | 5积分 |
| 每周成就 | - | ~3.5积分/天 |
| 每月成就 | - | ~2.6积分/天 |
| 广告(待开通) | - | 30积分 |
| **日均** | **~1积分** | **~17积分(无广告) / ~47积分(有广告)** |

**小程序积分获取能力 ≈ 网站的 17~47 倍**

## 八、数据库设计

### 8.1 成就定义表 (achievements)

```sql
CREATE TABLE achievements (
  id VARCHAR(32) PRIMARY KEY,         -- 成就ID
  name VARCHAR(50) NOT NULL,          -- 成就名称
  description VARCHAR(200),           -- 成就描述
  icon VARCHAR(10),                   -- 图标emoji
  category VARCHAR(20),               -- 分类: daily/weekly/monthly/permanent
  condition_type VARCHAR(30),         -- 条件类型: login_count/like_count/etc
  condition_value INT,                -- 达成所需值
  reward_credits DECIMAL(10,1),       -- 奖励积分
  sort_order INT DEFAULT 0,           -- 排序
  is_active TINYINT DEFAULT 1,        -- 是否启用
  created_at DATETIME DEFAULT NOW()
);
```

### 8.2 用户成就进度表 (user_achievements)

```sql
CREATE TABLE user_achievements (
  id INT PRIMARY KEY AUTO_INCREMENT,
  user_token VARCHAR(64) NOT NULL,    -- 用户标识
  achievement_id VARCHAR(32) NOT NULL,-- 成就ID
  current_value INT DEFAULT 0,        -- 当前进度值
  is_completed TINYINT DEFAULT 0,     -- 是否已完成
  is_claimed TINYINT DEFAULT 0,       -- 是否已领取
  completed_at DATETIME,              -- 完成时间
  claimed_at DATETIME,                -- 领取时间
  period_start DATE,                  -- 周期开始日期(用于重置)
  created_at DATETIME DEFAULT NOW(),
  updated_at DATETIME DEFAULT NOW(),
  
  UNIQUE KEY uk_user_achievement (user_token, achievement_id, period_start)
);
```

### 8.3 签到记录表 (user_checkins)

```sql
CREATE TABLE user_checkins (
  id INT PRIMARY KEY AUTO_INCREMENT,
  user_token VARCHAR(64) NOT NULL,
  checkin_date DATE NOT NULL,         -- 签到日期
  streak_days INT DEFAULT 1,          -- 连续签到天数
  reward_credits DECIMAL(10,1),       -- 获得积分
  created_at DATETIME DEFAULT NOW(),
  
  UNIQUE KEY uk_user_date (user_token, checkin_date)
);
```
