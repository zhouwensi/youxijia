# 通行证与兑换码核销（中心库 youxijia）

## 密钥配置（Cloudflare Secret）

在 **youxijia** Pages 项目（绑定 D1 的 Worker）中配置两个 **Secret 环境变量**（名字固定如下）：

- `HUB_SITE_SECRET_YOUXIMUDI`  
- `HUB_SITE_SECRET_XIYOU`  

**「一致」指：密钥内容（一串随机字符），不是 Worker 名字。**  
游戏墓地 Cloudflare 上的 Worker 脚本名可以叫 `youximudi-api` 或别的，与密钥无关；要求只有：**中心里存的 `HUB_SITE_SECRET_YOUXIMUDI` 的值**，和 **墓地 Worker 里同名 Secret 的值**，必须是**同一串**（墓地用它在转发请求时算 `X-Internal-Signature`，中心用同一串验签）。`HUB_SITE_SECRET_XIYOU` 同理：**中心**与 **本命测 Pages 项目**（如 `xiyou-benming-test`）里各配一份，**变量名相同、粘贴进去的字符串相同**。

落地命令（变量名一致；粘贴时两次用**同一段**密钥）：

- **youximudi** Worker：`wrangler secret put HUB_SITE_SECRET_YOUXIMUDI`  
- **xiyouce** Pages：`wrangler pages secret put HUB_SITE_SECRET_XIYOU --project-name xiyou-benming-test`  
- **youxijia** Pages：`wrangler pages secret put HUB_SITE_SECRET_YOUXIMUDI --project-name youxijia` 与 `... put HUB_SITE_SECRET_XIYOU ...`

## `api` 子域与 KV Worker（`yijuhuayouxi-api`）

若 **`https://api.yijuhuayouxi.com`** 仍绑在仓库根目录 **`worker/`** 的 KV Worker 上：小程序 **`/api/mp/privilege/*`**、本站 **`/api/hub/privilege/redeem`**、**`/api/hub/redeem-proxy`**（游戏墓地 / 本命测浏览器直连核销）、**`/api/hub/points-ledger`**、**`/api/hub/link-token/create`**、**`/api/hub/cross-entitlements`**、**`GET/POST /api/account`（含 `login` / `register` / `init`）**、**`PUT /api/account/nickname`**、**游戏详情留言**（**`GET/POST/DELETE /api/games/{id}/comments...`**）、**`GET/POST/DELETE /api/my-comments...`**、微信登录、D1 积分等依赖 **转发到 youxijia Pages Functions**（与 D1 `user_accounts` 同源）。Worker 会优先读 **`PAGES_API_ORIGIN`**（勿尾斜杠）；**未配置时默认转发到 `https://youxijia.pages.dev`**（与 Pages 项目名 `youxijia` 一致）。若你的 Pages 项目名不同，务必在 Cloudflare 设置 `PAGES_API_ORIGIN` 覆盖。`GET /api/site-config` 仍由本 Worker 直接响应（读广告位环境变量）。未列入转发白名单的 `/api/*` 会返回 **501「接口尚未在新后端实现」**。

## 接口一览（中心：`https://api.yijuhuayouxi.com`）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/mp/privilege/claim` | 小程序领取兑换码（需 `x-platform: miniprogram` + `X-User-Token`） |
| GET | `/api/mp/privilege/quotas` | 当日各类型领取次数 |
| GET | `/api/mp/privilege/my-codes` | 我的兑换码记录 |
| POST | `/api/mp/privilege/interstitial-log` | 插屏展示计数（每日上限 5） |
| POST | `/api/hub/privilege/redeem` | 本站已登录用户核销（`X-User-Token` + JSON `{ code }`） |
| POST | `/api/hub/redeem-proxy` | 子站浏览器直连中心核销（`X-User-Token` 或 `linkToken` + JSON `{ code, clientSite? }`；`clientSite` 为 `xiyou` 等时 `used_site=XIYOU`，否则 `YOUXIMUDI`） |
| POST | `/api/hub/link-token/create` | 生成通行证密钥（`X-User-Token`） |
| GET | `/api/hub/points-ledger` | 积分流水（`X-User-Token` 或 `?linkToken=`） |
| GET | `/api/hub/cross-entitlements` | 跨站权益 JSON（`?site=YIJUHUA|YOUXIMUDI|XIYOU` + token 或 linkToken） |
| POST | `/api/internal/hub/redeem` | **仅服务端**：子站 Worker 转发，`X-Internal-Site` + `X-Internal-Signature: sha256(secret + ":" + bodyRaw)` |

子站浏览器调用：

- 游戏墓地：`POST https://api.yijuhuayouxi.com/api/hub/redeem-proxy`（与主站同源 API；KV Worker 已列入转发白名单）  
- 本命测：同上（`clientSite: "xiyou"` 建议由前端传入，以便核销记录写入 `XIYOU`）

### 游戏墓地 / 本命测：通行证说明文案（可复制 HTML）

网页端可直接放外链，建议统一为：

```html
  → 底部「我的」→「💎 我的积分」→ 点「生成通行证密钥」复制后，回到本站粘贴。</p>
```

## 仅本人操作：详细步骤（按顺序做即可）

### 一、微信小程序（微信公众平台 + 开发者工具）

**前提**：使用小程序管理员或具备「开发 / 开发管理」权限的账号。

#### 1. 关联公众号（若首页/我的页用了 `<official-account>`）

1. 登录 [微信公众平台（小程序）](https://mp.weixin.qq.com)。  
2. 左侧 **设置** → **关联设置**（或 **账号设置** 下的 **关联公众号** / **相关小程序**，以当前后台菜单为准）。  
3. 按向导关联你的 **【游戏开发技术教程】** 对应公众号（主体需符合微信规则）。  
4. 关联成功后，小程序内公众号组件才可能正常展示；未关联时组件可能空白或报错。

#### 2. 服务器域名（request 合法域名）

1. 小程序后台 → **开发** → **开发管理** → **开发设置**。  
2. 找到 **服务器域名** → **request 合法域名**。  
3. 点击修改，添加（需已备案且 HTTPS 可访问）：  
   - `https://api.yijuhuayouxi.com`  
4. 保存。若提示需校验文件或备案信息，按微信提示完成（个人主体以后台实际要求为准）。  
5. 确认小程序代码里请求基址一致：`miniprogram/app.js` 中 `baseUrl` 为 `https://api.yijuhuayouxi.com`（若你改用其他 API 域，此处与合法域名必须一致）。

#### 3. 业务域名（一般个人工具类可跳过）

- 当前合规版若**未使用** `web-view` 打开 H5，通常**不必**配置业务域名。  
- 若以后企业主体启用 `web-view`，再在 **业务域名** 里添加对应 `https://` 站点，并按微信要求完成校验文件放置。

#### 4. 用户隐私与协议（提审前必看）

1. 小程序后台 → **设置** → **基本设置** / **服务内容声明** / **用户隐私保护指引**（菜单名以微信当前版本为准）。  
2. 根据小程序实际收集的信息（昵称、登录态等）填写隐私说明，与首屏 **`pages/consent`** 文案一致、无夸大。  
3. 保存后，在开发者工具用「真机调试」走一遍同意流程。

#### 5. 流量主广告位（微信公众平台内创建）

1. 小程序后台 → **推广** → **流量主**（需满足开通条件，如 UV 等，以微信说明为准）。  
2. 分别创建你需要的广告位类型，例如：**原生模板 Banner**、**激励视频**、**插屏**（按需）。  
3. 每个广告位创建后，复制 **广告位 ID**（类似 `adunit-xxxxxxxx`）。  
4. 使 **`GET https://api.yijuhuayouxi.com/api/site-config`** 的 JSON 返回中包含小程序已支持的字段（与 `miniprogram/app.js` 里 `loadSiteConfig` 读取的一致），例如：  
   - 顶层：`rewardedVideoAdUnitId`、`miniBannerAdUnitId`、`miniBannerMineAdUnitId`  
   - 或 `extraConfig.ads` 下：`rewardedVideoAdUnitId`、`miniBannerAdUnitId`、`miniBannerMineAdUnitId`、`interstitialAdUnitId`、`splashAdUnitId`  
5. 用浏览器直接打开上述 `site-config` 地址核对；保存后等 1～2 分钟，在开发者工具 **清除缓存 → 重新编译**，看控制台里站点配置是否带上非空 ID。  
6. **说明（当前 `api.yijuhuayouxi.com` 绑在 KV Worker `yijuhuayouxi-api` 时）**：在 Cloudflare → **Workers & Pages** → **yijuhuayouxi-api** → **Settings → Variables** 添加以下 **Variables**（或 `wrangler.toml` 的 `[vars]`，广告位 ID 非密钥也可用明文变量）：  
   - `REWARDED_VIDEO_AD_UNIT_ID`  
   - `MINI_BANNER_AD_UNIT_ID`、`MINI_BANNER_MINE_AD_UNIT_ID`  
   - `INTERSTITIAL_AD_UNIT_ID`、`SPLASH_AD_UNIT_ID`（按需）  
   保存后重新打开 `GET /api/site-config` 应出现与流量主后台一致的 ID；原则是 **接口返回与微信后台复制的单元 ID 一致**。  
   **封面广告 ≠ 上面的 `SPLASH_AD_UNIT_ID`。** 微信流量主里的 **封面广告** 多为后台 **开关 + 场景播控**，[官方说明](https://developers.weixin.qq.com/miniprogram/analysis/wedata/tool/coverad.html)里属于「进入小程序加载时机展示」、**不要求你在代码里填 `adunit`**，因此后台往往 **没有可复制到 Cloudflare 的 ID**——这是正常现象。`SPLASH_AD_UNIT_ID` 仅用于小程序端 **`wx.createSplashAd`**（若微信为你的类目/基础库提供了需填 `adUnitId` 的开屏形态）；没有该项时，代码会用 **插屏** 做冷启动兜底，**不影响**你在公众平台已开启的封面广告。  
   **Cloudflare 不能留空时**：在 **Variables** 列表里 **删除** `SPLASH_AD_UNIT_ID` 这一项即可（未定义即视为不用开屏 API）。若界面强制必填、不便删除，可填占位符 **`-`** 或 **`none`**（Worker 会当作未配置，接口里会变成空字符串）。

#### 6. 微信登录（若尚未配置服务端密钥）

1. 小程序后台 → **开发** → **开发管理** → **开发设置** → **AppID(小程序ID)**、**AppSecret(小程序密钥)**。  
2. 在 **Cloudflare** 上托管 `api.yijuhuayouxi.com` 的 **youxijia Pages**（或实际处理 `/api/wechat/login` 的项目）中，配置 Secret：`WX_MINI_APPID`、`WX_MINI_SECRET`（名称以 `functions/types.ts` / Worker 代码为准）。  
3. 勿将 AppSecret 提交到 Git。

#### 7. 上传代码、提交审核、发版

1. 本机安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，导入仓库目录 **`miniprogram/`**（或你实际的小程序根目录）。  
2. **详情** → **本地设置**：按需勾选「不校验合法域名」仅用于本机调试；**上传 / 提审前务必关闭**，确保走真实域名。  
3. 点击 **上传**，填写版本号与项目备注。  
4. 登录 [微信公众平台](https://mp.weixin.qq.com) → **管理** → **版本管理**。  
5. 在「开发版本」中找到刚上传的版本 → **提交审核**：选择类目（与「工具 / 权益兑换」等实际功能一致）、上传截图、填写测试账号说明等。  
6. 审核通过后，在 **版本管理** 中点击 **发布**。  
7. 发布后用自己的微信搜小程序，完整走：同意隐私 → 登录 → 首页/我的 → Banner / 激励视频 / 插屏（若已配置）各点一次，确认无违规文案、无强制看广告才能用基础功能等问题。

### 三、密钥轮换（仅在你主动要换 `HUB_SITE_SECRET_*` 时）

**原则**：同一密钥在「中心 + 对应子站」必须**同一字符串**；换密钥顺序建议「先中心、后子站」，窗口期内子站可能短暂核销失败。

1. 在本机生成一段足够长的随机串（示例，PowerShell）：  
   `[Convert]::ToBase64String((1..48 | ForEach-Object { Get-Random -Maximum 256 }) -as [byte[]])`  
   复制输出，**仅存密码管理器或离线安全处**，不要发聊天、不要写进仓库。

2. **中心 youxijia（Cloudflare Pages 项目 `youxijia`）** — 在 `youxijia` 仓库根目录、已 `wrangler login` 的终端执行：  
   - `npx wrangler pages secret put HUB_SITE_SECRET_YOUXIMUDI --project-name youxijia`  
   - `npx wrangler pages secret put HUB_SITE_SECRET_XIYOU --project-name youxijia`  
   按提示粘贴**新**密钥（若只轮换其中一个，另一个命令可跳过）。

3. **游戏墓地 Worker（项目名 `youximudi-api`）**：  
   - `cd youximudi/workers/api`（以你本机路径为准）  
   - `npx wrangler secret put HUB_SITE_SECRET_YOUXIMUDI`  
   粘贴与中心 **完全相同** 的 `YOUXIMUDI` 新值。

4. **本命测 Pages（项目名 `xiyou-benming-test`）**：  
   - `cd xiyouce`  
   - `npx wrangler pages secret put HUB_SITE_SECRET_XIYOU --project-name xiyou-benming-test`  
   粘贴与中心 **完全相同** 的 `XIYOU` 新值。

5. **验证**：在创作站登录 → 生成通行证 → 墓地/本命测保存后，各核销一张测试码；若 401/签名校验失败，检查三处是否漏改或复制了空格。

### 四、建议验收（可选，但强烈建议你做）

1. 浏览器打开 `https://www.yijuhuayouxi.com`，登录后找到通行证/密钥生成入口，生成并复制密钥。  
2. 打开游戏墓地站点 →「我的背包」粘贴保存；打开本命测站点路径 **`/pass`** 粘贴保存。
