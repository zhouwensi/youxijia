# 通行证与兑换码核销（中心库 youxijia）

## 密钥配置（Cloudflare Secret）

在 **youxijia** Pages 项目（绑定 D1 的 Worker）中：

- `HUB_SITE_SECRET_YOUXIMUDI`：与游戏墓地 Worker 一致  
- `HUB_SITE_SECRET_XIYOU`：与本命测 Pages 项目一致  

在 **youximudi** Worker：`wrangler secret put HUB_SITE_SECRET_YOUXIMUDI`（与上相同字符串）。

在 **xiyouce** Pages：`wrangler secret put HUB_SITE_SECRET_XIYOU`（与上相同字符串）。

## 接口一览（中心：`https://api.yijuhuayouxi.com`）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/mp/privilege/claim` | 小程序领取兑换码（需 `x-platform: miniprogram` + `X-User-Token`） |
| GET | `/api/mp/privilege/quotas` | 当日各类型领取次数 |
| GET | `/api/mp/privilege/my-codes` | 我的兑换码记录 |
| POST | `/api/mp/privilege/interstitial-log` | 插屏展示计数（每日上限 5） |
| POST | `/api/hub/privilege/redeem` | 本站已登录用户核销（`X-User-Token` + JSON `{ code }`） |
| POST | `/api/hub/link-token/create` | 生成通行证密钥（`X-User-Token`） |
| GET | `/api/hub/points-ledger` | 积分流水（`X-User-Token` 或 `?linkToken=`） |
| GET | `/api/hub/cross-entitlements` | 跨站权益 JSON（`?site=YIJUHUA|YOUXIMUDI|XIYOU` + token 或 linkToken） |
| POST | `/api/internal/hub/redeem` | **仅服务端**：子站 Worker 转发，`X-Internal-Site` + `X-Internal-Signature: sha256(secret + ":" + bodyRaw)` |

子站浏览器调用：

- 游戏墓地：`POST /api/hub/redeem-proxy`（同源 Worker 已转发）  
- 本命测：`POST /api/hub/redeem-proxy`（Pages Functions）

## D1 迁移

在 youxijia 仓库执行：`npm run cf:db:remote`（或随 `cf:deploy`）以应用 `migrations/0006_privilege_redeem.sql`。

## 小程序广告位

在站点配置或 `extraConfig.ads` 中提供：`miniBannerAdUnitId`、`miniBannerMineAdUnitId`、`rewardedVideoAdUnitId`、`interstitialAdUnitId`（可选 `splashAdUnitId`）。未配置时对应组件会降级为空或提示。

`HUB_SITE_SECRET_YOUXIMUDI`、`HUB_SITE_SECRET_XIYOU` 已在 Cloudflare 侧分别写入 **youxijia Pages**、**youximudi-api Worker**、**xiyou-benming-test Pages**（两处 Pages 与中心一致）。若你**轮换**密钥，务必三处同步更新。

## 上线后建议你亲自核对的事项（清单）

1. **微信小程序**  
   - 在微信公众平台配置：服务器域名、`业务域名`（若用到）、**流量主广告位 ID**，并与后台 `site-config` / `extraConfig.ads` 或小程序端展示一致。  
   - 用开发者工具真机预览：首页/我的、激励视频、Banner、插屏（关闭兑换码弹窗后）是否符合预期。  
   - 提交审核前对照合规自检（无外链文案、无强制看广告领基础码等）。

2. **子站部署**  
   - **本命测**：在 `xiyouce` 目录执行 `npm run deploy`（或你现有 CI），使 `PassHub`、结果页引导、`/api/hub/redeem-proxy` 等到生产环境。  
   - **游戏墓地**：在 `youximudi/workers/api` 执行 `npx wrangler deploy`，并确认 GitHub Pages / 路由仍指向该 Worker。

3. **联调抽检**  
   - 在创作主站生成通行证密钥 → 在墓地「我的背包」、本命测 `/pass` 粘贴保存 → 各站分别核销一张测试码（或等真实码），看积分与权益 JSON 是否更新。

4. **密钥轮换（可选）**  
   - 若需更换 Secret：用 `wrangler pages secret put` / `wrangler secret put` 在三处写入**同一新值**，并自行记录到安全位置（仓库内勿明文保存）。
