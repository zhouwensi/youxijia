# TabBar 图标说明

## 需要的图标文件

每个图标需要两个版本：普通状态和选中状态

### 创作 Tab
- `create.png` - 普通状态（灰色）
- `create-active.png` - 选中状态（青色）

### 排行 Tab
- `rank.png` - 普通状态（灰色）
- `rank-active.png` - 选中状态（青色）

### 我的 Tab
- `mine.png` - 普通状态（灰色）
- `mine-active.png` - 选中状态（青色）

## 图标规格

- 尺寸：81px × 81px（建议提供 @2x 和 @3x 版本）
- 格式：PNG（支持透明背景）
- 颜色：
  - 普通状态：#8b8b8b（灰色）
  - 选中状态：#00d4ff（青色）

## 图标设计建议

- **创作**：画笔、魔法棒、闪烁的星星
- **排行**：奖杯、排行榜、皇冠
- **我的**：用户头像、人形图标

## 临时方案

如果暂时没有图标，可以使用纯色占位图片，小程序仍可正常运行。
