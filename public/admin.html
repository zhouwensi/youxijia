🔒 功能开关配置

启用后，用户无法在网站上创作新游戏，点击"创作"按钮会引导到小程序。

启用后，用户无法在网站上编辑或修复游戏，相关按钮会引导到小程序。

启用后，用户无法在网站上点赞、收藏、评论、关注等，相关操作会引导到小程序。 （默认关闭，允许网站用户互动）

💡 配置说明：
• 创作 + 编辑都禁用 = 旧版"禁用网站写操作"的效果
• 可单独开放互动功能，让用户在网站上也能点赞、收藏、评论
• 已登录用户始终可以查看自己的个人主页（点赞/收藏/作品列表）

💡 配置小程序信息后，网站禁用写操作时会尝试跳转小程序，无法跳转则显示小程序二维码。

📱 小程序功能开关

以下设置仅影响微信小程序端，不会影响网页版的功能。

启用后，小程序中将隐藏所有评论相关的UI（评论区、评论输入框、评论数统计），用户无法在小程序中发表或查看评论。

启用后，小程序中将隐藏LLM设置入口，用户无法在小程序中配置自定义LLM模型和API Key。

💡 配置说明

• 评论功能：关闭后，游戏详情页不显示评论区，也不显示评论数统计

• LLM设置：关闭后，"我的"页面不显示LLM设置入口

• 以上设置仅对小程序有效，网页版功能不受影响

• 修改后需要用户重新打开小程序才能生效

🤖 大模型配置

配置可用的AI大模型，包括预计生成时间、积分消耗、API Key等

用户未选择模型时将使用此模型
启用 模型名称 提供商 速度 效果等级 消耗积分 最大Token 默认 API Key 状态

💡 配置说明：
• 启用开关：只有启用的模型才会在前端显示供用户选择（默认只启用 DeepSeek 和 Gemini）
• 速度等级：用于前端显示模型响应速度标签
• 消耗积分：设为0表示免费使用（需用户自备Key或使用默认Key）
• 最大Token：模型生成时的最大输出Token数，影响生成的游戏代码长度
• 默认 API Key：当用户未配置自己的Key时使用，留空则需用户自行配置
• 效果等级：仅供参考，不影响实际使用
