========================================
  一键游戏开发平台 - 快速安装指南
========================================

【第一步】安装 Node.js

您的系统尚未安装 Node.js，需要先安装才能运行本项目。

安装方法：

方法一：直接下载（推荐，最简单）
1. 打开浏览器，访问：https://nodejs.org/
2. 点击下载 LTS（长期支持）版本（推荐版本）
3. 下载完成后，双击运行安装程序
4. 安装过程中，确保勾选"Add to PATH"选项
5. 点击"Install"完成安装

方法二：使用包管理器（如果您已安装）
- 如果已安装 winget，运行：
  winget install OpenJS.NodeJS.LTS

- 如果已安装 Chocolatey，运行：
  choco install nodejs


【第二步】验证安装

1. 安装完成后，关闭所有终端/命令提示符窗口
2. 重新打开一个新的终端/命令提示符
3. 运行以下命令：
   node --version
   npm --version
4. 如果显示版本号（如 v20.x.x），说明安装成功


【第三步】安装项目依赖

1. 在项目目录下，运行：
   npm install
   
   这将安装所有必需的依赖包，可能需要几分钟时间


【第四步】启动项目

运行以下命令启动开发服务器：
   npm run dev

然后在浏览器中访问：
   http://localhost:3000


【快速方式】

您也可以直接运行项目目录下的 setup.bat 文件：
   双击 setup.bat

这个脚本会自动检测环境并指导您完成安装。


【遇到问题？】

1. 如果提示"npm 不是内部或外部命令"：
   - 确保已安装 Node.js
   - 重启终端/命令提示符
   - 检查 Node.js 是否正确添加到系统 PATH

2. 如果端口被占用：
   - 可以修改 vite.config.ts 中的端口号

3. 如果依赖安装失败：
   - 尝试清除缓存：npm cache clean --force
   - 然后重新安装：npm install

4. 其他问题：
   - 查看 SETUP.md 文件获取更详细的说明


祝您使用愉快！
